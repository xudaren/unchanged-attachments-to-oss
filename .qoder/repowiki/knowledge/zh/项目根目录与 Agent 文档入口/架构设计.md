本模块为纯文档型根目录，不含源码：
- `README.md` 仅给出仓库名称与一句话中文简介。
- `AGENTS.md` 与 `CLAUDE.md` 内容完全一致，作为 Agent 下钻式查阅的全局入口，按「是什么 / 为什么 / 怎么样（流程、约束、规则）」三段式描述 Obsidian 插件能力（OSS 参数配置、上传感知替换路径、动态签名渲染、联动删除）。
- `.claude/settings.local.json` 通过 `permissions.allow` 白名单允许 Bash 软链接/硬链接命令，使 `AGENTS.md` 始终指向 `CLAUDE.md`，从而在 Windows 与 Unix 环境下保持双文件名同步，避免重复维护两份相同文档。
