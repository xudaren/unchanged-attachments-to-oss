# 文档结构

本目录存放 `CLAUDE.md` 下钻的功能设计文档。

- 一个功能域一个文件，使用 kebab-case 英文命名。
- `CLAUDE.md` 只保留项目总览、全局约束、工作规则和本目录索引。
- 功能流程、局部边界及异常语义写入对应专题文档；跨功能约束仍保留在 `CLAUDE.md`。
- 专题文档统一使用 `是什么 → 为什么 → 怎么样`；`怎么样` 按需包含 `流程 → 约束 → 规则`，不适用的子章节可省略。
- 新增功能域时先更新本索引和根文档引用，再创建专题文档。
- 功能移除后同步删除根文档引用及无其他引用的专题文档。
